# Happy Birthday あいら

A static React + Vite birthday website.

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- Node: 22 (configured in `netlify.toml`)

The project does not require a server, database, authentication, TanStack Start, or generated route tree.

## GitHub

Upload the **contents of this folder** to the repository root (not the ZIP itself). Then import the repository into Netlify.
